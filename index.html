Perguntas frequentes

Antes de começar

Preciso saber programar?

Não. Comece pelas aulas iniciais e aprenda Luau aos poucos com exemplos pequenos.

Posso criar jogos pelo celular?

O Roblox Studio completo é para computadores Windows e macOS. No celular você pode estudar e planejar, mas não substituir todas as ferramentas do Studio.

O que é Luau?

Luau é a linguagem de programação usada no Roblox, baseada em Lua e adaptada para a plataforma.

Como publico meu jogo?

Use as opções de publicação do Studio e configure nome, descrição, ícone, imagens e permissões no Creator Dashboard.

Posso adaptar os exemplos?

Sim. Use os trechos como ponto de partida, entenda onde cada script deve ficar e teste em um projeto separado.
